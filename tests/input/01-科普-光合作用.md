# 光合作用：植物如何把阳光变成食物

提到植物，很多人第一反应是"绿色""会进行光合作用"。但光合作用到底是什么？它其实是一系列复杂的化学反应，把光能转化为化学能，最终储存在糖类分子里。

光合作用发生在植物的叶绿体中。叶绿体里有一种关键的色素叫叶绿素，它呈现绿色，能吸收太阳光中的红光和蓝紫光，而绿光被反射出来，所以我们看到的叶子是绿色的。

整个过程分为两个阶段。第一阶段叫光反应，发生在叶绿体的类囊体膜上。叶绿素吸收光能后，将水分子分解，释放出氧气，同时把光能转化为化学能，储存在两种能量载体里：ATP 和 NADPH。第二阶段叫暗反应（也叫卡尔文循环），发生在叶绿体的基质中，不需要光直接参与。暗反应利用光反应产生的 ATP 和 NADPH 提供的能量，把空气中的二氧化碳固定并还原，最终合成葡萄糖等有机物。

如果用一句话概括光合作用的总反应式，那就是：二氧化碳 + 水，在光照和叶绿体的作用下，生成葡萄糖和氧气。

光合作用对整个地球生态意义重大。它一方面把太阳能固定为化学能，成为几乎所有生物的能量来源——我们吃的粮食、烧的煤炭，追根溯源都来自光合作用固定的能量。另一方面，它吸收二氧化碳、释放氧气，维持了大气中氧气和二氧化碳的平衡，这也是地球能孕育生命的重要前提。

值得一提的是，光合作用释放的氧气其实来自水的分解，而不是来自二氧化碳。这个结论是通过同位素示踪实验证实的：科学家用含氧-18 同位素标记的水参与光合作用，结果发现释放的氧气带有氧-18，而用标记的二氧化碳时，氧气中却没有氧-18。这个实验也说明，科学结论要靠实验证据来支撑，不能凭直觉猜测。
