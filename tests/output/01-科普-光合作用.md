# 知识卡片（7 张）· 《光合作用：植物如何把阳光变成食物》

## 1. 光合作用的定义与场所
**核心知识**：光合作用是把光能转化为化学能并储存在糖类中的一系列化学反应，发生在叶绿体内。
**简明解释**：植物通过光合作用把太阳能变成自己能用的化学能。反应场所是细胞中的叶绿体，其中含有关键色素叶绿素，是反应的"机器"。
**自测问题**：光合作用发生在植物细胞的哪个结构里？答案：叶绿体。

## 2. 叶绿素为什么是绿色的
**核心知识**：叶绿素能吸收红光和蓝紫光、反射绿光，所以叶子呈绿色。
**简明解释**：叶绿素不是"喜欢绿色"，而是恰好不吸收绿光，把绿光反射回我们眼睛里，人眼因此看到绿色。真正参与光合作用的光是红光和蓝紫光。
**例子**：太阳光包含各种颜色，叶绿素选择性吸收其中的红光和蓝紫光用于光反应，绿光被反射，叶子因此显绿。

## 3. 光反应：把光能变成化学能
**核心知识**：光反应在类囊体膜上进行，分解水释放氧气，同时生成 ATP 和 NADPH 两种能量载体。
**简明解释**：这是光合作用的第一阶段，必须要有光。叶绿素吸收光能后驱动水分子分解（释放氧气），光能随之被储存在 ATP 和 NADPH 中，供下一阶段使用。
**自测问题**：光反应发生在叶绿体的哪个部位？产物有哪些？答案：类囊体膜；产物是氧气、ATP 和 NADPH。

## 4. 暗反应：固定二氧化碳合成糖
**核心知识**：暗反应（卡尔文循环）发生在叶绿体基质中，利用光反应提供的 ATP 和 NADPH，把二氧化碳固定并还原成葡萄糖。
**简明解释**：这一阶段不需要光直接参与，所以叫"暗反应"。它消耗光反应产出的能量载体，把空气中的二氧化碳"加工"成有机物，完成从无机碳到有机糖的转化。
**自测问题**：暗反应发生在叶绿体的哪个部位，需要什么能量来源？答案：基质；依赖光反应产生的 ATP 和 NADPH。

## 5. 光合作用的总反应式
**核心知识**：二氧化碳 + 水 →（光照、叶绿体）葡萄糖 + 氧气。
**简明解释**：一句话概括光合作用的原料（二氧化碳和水）、条件（光照和叶绿体）和产物（葡萄糖和氧气），是理解整个过程的"压缩包"。
**自测问题**：写出光合作用的总反应式。答案：二氧化碳 + 水，在光照和叶绿体作用下生成葡萄糖和氧气。

## 6. 光合作用的地球意义
**核心知识**：光合作用固定太阳能成为几乎所有生物的能量来源，并吸收二氧化碳、释放氧气，维持大气气体平衡。
**简明解释**：地球上的粮食和化石能源，追根溯源都是光合作用固定的太阳能；同时它调节大气中氧气和二氧化碳的含量，是生命存续的前提。
**例子**：我们吃的大米、燃烧的煤炭，能量最初都来自光合作用固定的太阳能。

## 7. 氧气来自水：同位素示踪实验
**核心知识**：光合作用释放的氧气来自水的分解，而非二氧化碳；该结论由同位素示踪实验证实。
**简明解释**：科学家用含氧-18 同位素标记的水参与光合作用，释放的氧气带有氧-18；而标记二氧化碳时氧气中没有氧-18。这证明氧气来源于水，也说明科学结论需要实验证据。
**自测问题**：如何证明光合作用放出的氧气来自水而不是二氧化碳？答案：用含氧-18 的水做同位素标记，观察释放氧气的同位素组成。
