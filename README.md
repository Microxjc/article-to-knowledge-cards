# knowledge-cards-mark

把一篇文章浓缩成 5~8 张结构化知识卡片，支持文本与图片两种输出，用于学习、复习和知识沉淀。可开源分发，也可直接被 AI Agent 以 Skill 方式加载。

## 1. 项目解决什么问题

读完一篇长文后，信息量大、结构散，很难快速抓住重点并形成可复习的知识点。本项目把"阅读 → 提炼 → 复习"中重复且费时的提炼环节自动化：输入一篇文章（粘贴正文或本地 `.md`/`.txt` 文件），输出一组互相独立、忠于原文的知识卡片，每张卡片只讲一个知识点，方便按卡复习、记忆和分享。

同时解决"知识卡片怎么展示"的问题：除 Markdown 文本外，可一键渲染为统一版式的 PNG 图片卡片（单卡或合并长图），文字与文本卡片逐字一致，适合手机阅读和社交分享。

## 2. 主要方法

采用"**文本提炼 + 图片渲染**"两阶段流水线：

**阶段一：文本提炼（由 AI Agent 按 `SKILL.md` 规则执行）**
- 通读全文，筛选真正重要的独立知识点（不是每段都做卡）；
- 一张卡片只讲一个知识点，删除重复内容；
- 不编造：所有数字、定义、结论、例子必须来自原文，原文无实例时改用自测问题；
- 信息不足时不凑数：卡片数 5~8 张，原文支撑不了 5 张时按实际数量输出并注明原因。

**阶段二：图片渲染（`scripts/render_cards.py`，Pillow 确定性排版）**
- 解析阶段一的 Markdown 卡片输出，按统一版式绘制：白底圆角外框、深蓝标题栏、三色字段标签（核心知识 / 简明解释 / 例子或自测问题）；
- 两种输出模式：每卡一张 PNG（1080×1350）或 `--sheet` 合并为 1 张纵向长图（顶部文章标题横幅 + 逐张卡片单元）；
- 自动检测系统中文字体（Windows 微软雅黑 / 黑体、macOS 苹方、Linux Noto CJK），支持 `--scale` 高清放大；
- 图片仅做排版呈现，不增删、不改写卡片文字。

## 3. 安装方法

**作为 Skill 使用（零安装）**：把 `skills/knowledge-cards-mark` 目录放入 AI Agent 的 Skills 目录即可加载。

**图片渲染脚本需要 Python 3.8+ 与 Pillow：**

```bash
pip install pillow          # 渲染 PNG
pip install pyyaml          # 仅运行官方 quick_validate.py 验证时需要（可选）
```

中文字体无需手动安装：脚本会自动从系统字体中查找，也可用 `--font` / `--bold-font` 指定字体文件路径。

## 4. 使用方法

**方式 A：作为 Skill 使用**
1. 向 Agent 提出转换请求，例如："把这篇文章转换成知识卡片"；
2. 输入方式二选一：直接粘贴文章正文，或提供本地 `.md` / `.txt` 文件路径；
3. 需要图片时加一句"把卡片做成图片"（默认每卡一张 PNG），或"把卡片合并成一张长图"（`--sheet` 模式）；Agent 会先产出 Markdown 卡片，再调用渲染脚本，并同时保留文本版本。

**方式 B：直接命令行渲染已有卡片 Markdown**

```bash
python skills/knowledge-cards-mark/scripts/render_cards.py <cards.md> [--out 输出目录] [--scale 2]
python skills/knowledge-cards-mark/scripts/render_cards.py <cards.md> --sheet [--sheet-name 文件名]
```

- 默认输出到 `<cards.md>` 同目录的 `cards/` 子目录（每卡一张 PNG）；`--sheet` 输出 1 张合并长图；
- `--scale 2` 输出高清版（单卡 2160×2700）；
- 输入需符合 SKILL.md 定义的卡片格式（`## N. 标题` + `**字段**：内容`）。

## 5. 输入输出示例

**输入（文章片段，粘贴或存为 .md/.txt）**

> 光合作用发生在植物的叶绿体中。叶绿体里有一种关键的色素叫叶绿素，它能吸收太阳光中的红光和蓝紫光，而绿光被反射出来，所以我们看到的叶子是绿色的。整个过程分为两个阶段：光反应发生在类囊体膜上，分解水释放氧气，生成 ATP 和 NADPH；暗反应发生在基质中，利用 ATP 和 NADPH 把二氧化碳固定成葡萄糖。

**输出一：知识卡片（Markdown）**

```markdown
# 知识卡片（3 张）· 《光合作用》

## 1. 叶绿素为什么是绿色的
**核心知识**：叶绿素吸收红光和蓝紫光、反射绿光，所以叶子呈绿色。
**简明解释**：叶绿素不是"喜欢绿色"，而是恰好不吸收绿光，把绿光反射回眼睛里，人眼因此看到绿色。
**例子**：叶子吸收红光和蓝紫光用于光合作用，绿光被反射，叶子因此显绿。

## 2. 光反应
**核心知识**：光反应发生在类囊体膜上，分解水释放氧气，生成 ATP 和 NADPH。
**简明解释**：这是光合作用的第一阶段，必须有光参与，产物供暗反应使用。
**自测问题**：光反应发生在叶绿体的哪个部位？答案：类囊体膜。

## 3. 暗反应
**核心知识**：暗反应发生在基质中，利用 ATP 和 NADPH 把二氧化碳固定成葡萄糖。
**简明解释**：这一阶段不需要光直接参与，消耗光反应的产物完成二氧化碳到有机物的转化。
**自测问题**：暗反应的能量来自哪里？答案：光反应产生的 ATP 和 NADPH。
```

**输出二：图片卡片（PNG）**

- 单卡模式：`cards/01-叶绿素为什么是绿色的.png`（1080×1350）；
- 合并长图模式：`cards/《文章标题》-知识卡片.png`（宽 1080，高随内容自适应）。

## 目录结构

```
Know_Card_skill/
├── README.md
├── LICENSE               # MIT License
├── skills/
│   └── knowledge-cards-mark/
│       ├── SKILL.md            # Skill 定义与转换规则
│       ├── agents/
│       │   └── openai.yaml     # Agent 平台元信息（OpenAI 兼容格式）
│       └── scripts/
│           └── render_cards.py # Markdown 卡片 → PNG 图片卡片（单卡 / --sheet 长图）
└── tests/                      # 测试输入、文本输出与渲染图片
    ├── input/                  # 5 篇不同体裁测试文章（科普/技术/人文/短文/专著导览）
    └── output/                 # 对应文本卡片 + cards/ 目录（24 张 PNG）
```

## 不支持的输入

网页抓取、PDF 文件、Anki 导入格式、图形界面。遇到这些输入，请改为粘贴正文或提供 `.md` / `.txt` 文件。

## 测试

`tests/` 目录包含 5 篇不同体裁的测试输入（科普 / 技术 / 人文 / 短文本 / 专著章节导览）、对应文本输出，以及渲染出的 24 张图片卡片（23 张单卡 + 1 张合并长图）。验证口径：卡片数 5~8 张、格式统一、内容不超出来文、短文本不凑数、图片文字与文本卡片逐字一致；`scripts/render_cards.py` 渲染结果经 OCR 抽查核验。
